# Posterior Fossa Society website images

Photos used on the Society's website (Meetings page), served by GitHub Pages at
https://stumcafee.github.io/pfs-images/

## Meeting photos (folder `meetings/`)
The Meetings page looks for these exact file names. A photo appears as soon as its file is here,
and stays hidden until then.

| File | Meeting |
|---|---|
| 2026-copenhagen.jpg | 3rd Global Meeting, Copenhagen, April 2026 |
| 2024-memphis.jpg | 2nd Global Meeting, Memphis, April 2024 (included) |
| 2022-liverpool.jpg | 1st Global Meeting, Liverpool, September 2022 |
| 2021-virtual.jpg | Virtual meeting, June 2021 |
| 2018-reykjavik.jpg | Consensus Meeting, Reykjavik, August 2018 |

Before adding a photo, make it web-sized: about 1800 pixels wide and under 1 MB.
Only publish group photos the Society has permission to share.
